# 分支差異分析報告模板

## 1. 變更總覽
- **來源分支**：`source_branch`
- **目標分支**：`target_branch`
- **受影響模組**：列出主要的目錄或功能模組。

## 2. 深度技術分析
- **核心邏輯修改**：詳細描述演算法、狀態機或資料流的變更。
- **介面與協定**：是否修改了 API、函式簽名或通訊協定（如 EKF 參數、MAVLink 訊息）。

## 3. 風險與影響評估
- **破壞性修改**：是否會導致舊版不相容？
- **效能影響**：是否增加運算開銷或記憶體佔用？
- **建議測試點**：針對此次變更，測試人員應重點關注的部分。
