6.4.3.  Change  of the  Main  COM Port Baud Rate  
COM1 is the main COM -port. It is used for commands and data transfer between the 
INS unit and the host computer.  
The default baud rate for the INS COM1 port is set to 115200 bps (maximum for the 
standard COM -port). However, the INS supports different baud rates:  
• 4800 bps ; 
• 9600 bps ; 
• 14400 bps ; 
• 19200 bps ; 
• 38400 bps ; 
• 57600 bps ; 
• 115200 bps ; 
• 230400 bps ; 
• 460800 bps.  
There are two ways to change INS COM1 port baud rate: via INS -U GUI (see User 
Manual, Section  “6.2.1.1 . Change of the Main COM -Port Baud Rate”), and via the 
command 0x01 COM1_bps (see Table 6.58). 
Note:  That the same baud rate must be set for COM -port of the host computer.  
6.4.4.  PPS Description  
The INS unit outputs the pulse per second (PPS) signal generated by the onboard 
GNSS receiver through appropriate pin of the INS main connector.  
If the INS unit is configured for operation with external GNSS receiver, it is highly 
recommended to configure the INS unit to input PPS signal from this receiver on that 
PPS pin of the INS connector to synchronize INS calculations and data output with 
the source of PPS. In this case, all of the adjustable PPS parameters should 
correspond with the actual provided PPS signal.  
The leading edge of the PPS pulse is always the trigger / reference:  
• Negative – generates a normally high, active low pulse with the falling 
edge as the reference . 
• Positive – generates a normally low, active high pulse with the rising edge 
as the reference .
