# Git 提交訊息格式規範 (繁體中文)

## 結構
1. 首行：一句話摘要核心目標。
2. 內容：以 `- ` 開頭的詳細技術修改點。

### 模板
```text
<核心變更的一句話摘要>
- <具體技術細節 A>
- <具體技術細節 B>
```

## 語言原則
- **強制繁體**：嚴禁簡體中文。
- **術語保留**：技術術語（如 `API`, `Callback`, `Refactoring`）保留英文。

## 精簡版
保留一句摘要，並以最多兩個精簡項目列出最重要的技術修改；省略延伸背景與次要細節。

```text
修正 MUX 通道選擇與 DTC 斷線切換
- 修正 PB3 通道反相映射並加入讀回診斷
- 新增 setauto，將 DTC 逾時門檻調整為 10 次
```

## 範例
優化專案相依性管理
 - 更新 .venv 環境配置
 - 修正 README.md 中的安裝指南
 - 移除不再使用的測試腳本
