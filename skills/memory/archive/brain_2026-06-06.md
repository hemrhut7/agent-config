### Achievements
- **Default DTR/RTS Set to None**: Modified `SerialConnector` to set `dtr = None` and `rts = None` by default, preventing automatic control line toggles and unintended micro-controller resets on serial connection.
- **FIFO Telemetry Packet Queue**: Refactored `ABCReader.getData()` and `ABCReader_UDP.getData()` to check the local buffer first and return parsed packets immediately in a First-In-First-Out (FIFO) queue. The blocking `readAll()` is only called when the buffer contains no complete packets. This resolves the buffer overflow issue (`Buffer overflow, clearing buffer`) and allows UDP telemetry to reach the full 250Hz transmission rate without packet loss.
